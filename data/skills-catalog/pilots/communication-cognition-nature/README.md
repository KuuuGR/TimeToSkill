# pack-04 — Communication, cognition, nature and navigation

This folder contains a completed editorial pilot based on the 126-candidate pack received from the user.

- `approved-skill-pilot-pack-04-communication-cognition-nature.jsonl`: 35 skill proposals, each with exactly three levels, a chosen emoji, and source candidate IDs.
- `review-decisions-pack-04-communication-cognition-nature.jsonl`: one editorial decision for every source candidate.
- `additional-sources.json`: more specific official pages consulted to clarify several Purdue OWL topics and support navigation/learning candidates. The `source_id` values reference the source-family IDs present in the original pack; Cursor should verify source registry treatment during integration.
- `review-summary.md`: decisions and known limitations.

All accepted skills are **pilot proposals only**, not production-approved app content. Content for levels is authored editorial adaptation, not copied source text. Source candidate records were not modified.
