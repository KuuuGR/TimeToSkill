# Ruch, sport i taniec — pakiet pilotażowy

Pliki:
- `approved-skill-pilot-movement-sport-dance.jsonl` — autorskie propozycje skillów z trzema poziomami.
- `review-decisions-movement-sport-dance.jsonl` — jedna decyzja dla każdej z 102 kandydatur.
- `additional-sources.json` — lokalny indeks źródeł użytych w tym pilotażu. Zostaje jako ślad pochodzenia. Te same identyfikatory są w centralnym rejestrze `data/skills-catalog/research/sources.json` (`records_written` 0, bo nie dopisano z nich kandydatur). Rejestr centralny jest źródłem referencyjnym.
- `review-summary.md` — streszczenie decyzji i ograniczeń.

To materiał do recenzji, nie import produkcyjny. `additional-sources.json` nie zastępuje rejestru centralnego.
