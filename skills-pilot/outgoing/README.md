# Paczki wychodzące

Ten katalog nie jest miejscem, w którym użytkownik zostawia nowe pilotaże. Paczki przychodzące zostają w `skills-pilot/` obok tego folderu i nie są tu edytowane.

Pliki w `outgoing/` są kopiami gotowymi do przekazania zewnętrznej recenzji, na przykład do ChatGPT. Kanonik zostaje w `data/skills-catalog/archives/`. Skopiowanie nie zmienia statusu pakietu na `reviewed`.
